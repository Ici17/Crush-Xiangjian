# Crush香鉴 — 9 个核心场景剧本（设计师出图参照）

> **用途**：把「产品感觉」翻译成「画面」。设计师拿这 9 张关键帧就能开稿，不用猜我想要什么情绪。
> **基准**：iPhone 14 Pro Max（430×932）
> **氛围**：暖琥珀 + 奶油 + 衬线字体 = **深夜香水店** 的温度
> **核心比喻**：想象走进一条不张扬的小巷，拐角处有一家没挂招牌的香水店。
> 老板娘递给你试香纸时轻声说：「涂在手腕，等它醒来」。

---

## 阅读指南

- 每个场景包含 4 块：**情境** / **用户情绪** / **画面关键帧** / **设计师该干嘛**
- 关键帧描述参考漫画脚本，**给出构图 + 色彩 + 文字层级**，不指定具体字色值
- 出图顺序：**先做场景 1、2、3（落地 + 揭晓）**，这两个是产品情绪顶点
- 5 张分享图是裂变物料，单独按场景 6–9 出

## 场景 1：深夜刷朋友圈，遇见 Crush

### 情境

```
时间：周四 23:47
地点：被窝，手机屏幕微亮
人物：Lina，27 岁，白领，刚分手两个月
行为：刷朋友圈刷到好友分享的 Crush 香水测试图
      「她的本命香是「暗流」——这说的不就是我前男友吗」
      「我也想测」
```

### 用户情绪

```
好奇（60%）+ 一丝仪式感期待（30%）+ 怕被坑（10%）
```

### 画面关键帧

**朋友圈卡片（H5 入口物料）**

```
┌─────────────────────────┐
│ ░░░ 朋友圈缩略图 ░░░    │
│                         │
│      ▁                  │
│   ░░░░░░░   ← 琥珀暖光  │
│   ░░░░░░░     渐变圆角  │
│   ░░░░░░░     玻璃质感  │
│                         │
│      暗流                │
│                         │
│ 「不喧哗，但无法被忽视」│
│                         │
│ ═══ CRUSH FRAGRANCE ══ │
│                         │
│ ▣▣▣▣░░░░ 扫码测你的本命香 │
└─────────────────────────┘
```

**视觉意图**：
- **缩略图就要有质感**：不是截图，是品牌级海报
- 暖色调，**不要在深夜推送里刺眼**
- 「暗流」二字是焦点，**够大、够独特**
- 底部二维码 200px 圆角矩，**不要硬方角**

### 设计师该干嘛

出 4 张朋友圈展示位（横屏方形缩略 9:16 竖屏朋友圈）：

| # | 文案 |
|---|------|
| 1a | 我的本命香是「暗流」 |
| 1b | 测完测完，测出我的灵魂香气是「残温」 |
| 1c | 不喧哗，但无法被忽视 |
| 1d | 我的气味是「渊海」，你的是什么？ |

## 场景 2：进入落地页，30 秒判断值不值做

### 情境

```
时间：23:50
动作：点击 → 加载 1.2s → 看到落地页首屏
心理预算：3 秒内决定滚走还是继续看
```

### 用户情绪

```
好奇（峰值）→ 1.5 秒判断要不要继续
```

### 画面关键帧

**落地页首屏（430×932 全屏可见）**

```
│   ░░░░░░ + 线性渐变蒙版压暗 30% ░│
│   ░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│                                    │
│                                    │

│                                    │
│     用 10 道情境题                 │  ← 副标题 16px 手写
│     找到你气味里的灵魂            │
│                                    │
│      ┌──────────────────────┐    │
│      │  开始寻找我的本命香 →  │    │  ← 主 CTA 56px 高
│      └──────────────────────┘    │
│                                    │
│                                    │

│                                    │
│  [暗流] [荒岛] [残温] [裂岸]  ← 横滑人格预览胶囊  │  ← 微动效

```

**视觉意图**：
- **首屏不滚动可见主标题+CTA**（铁律 1）
- 氛围图让用户**感到温度**，不是漂亮图片，是「一种氛围」
- CTA 是全屏最大动作按钮，**用户眼睛第一落点**
- 数据条 + 人格胶囊是**信任锚**：真实、有料、不浮夸

### 设计师该干嘛

**出 2 稿**：
1. **氛围图主导版**（图占 50%）— 适合品牌冷启动期
2. **极简留白版**（图只占顶部 30%）— 适合转介绍流量

设计师可自由取舍，但 **CTA 一定要最强视觉重量**。

## 场景 3：沉浸式答题，做完 7 道没察觉时间过

### 情境

```
时间：00:05
动作：点击 CTA → 进入问卷页
      第 1 题「推开书店的旧书架，你闻到了什么？」
      选了「旧纸页的微苦」
      第 2 题「雨天老宅，一杯红茶」
      ... 30 秒过去了 ...
      第 7 题「快到末尾了，再坚持一下」
```

### 用户情绪

```
沉浸（沉浸曲线上升）→ 不要被打断
```

### 画面关键帧

**问卷页题目态**

```
┌────────────────────────────────────┐
│ [←] ▓▓▓▓▓▓▓░░░░ 7/10 [跳过?] │  ← 进度条 4px 高
│                                    │
│                                    │
│                                    │
│   想象你推开一家书店的旧书架，    │  ← 题面 24px 衬线
│   角落里有淡淡的旧木香，          │    居中
│   你闻到了什么？                  │
│                                    │
│                                    │
│   ┌──────────────┬──────────────┐ │
│   │              │              │ │
│   │ 旧纸页的微苦 │ 木质书架的暖 │ │  ← 选项 18px
│   │ 像时间过去   │ 像有人替你   │ │    双列卡片
│   │ 的味道       │ 留了灯       │ │    圆角 20
│   │              │              │ │    未选淡灰
│   │      📜      │      🕯️      │ │    选中金棕
│   └──────────────┴──────────────┘ │
│                                    │
│                                    │
└────────────────────────────────────┘
```

**视觉意图**：
- 题面要**像在读一句诗**，不要像问卷
- 选项也要**像诗行**，不要像 A/B/C/D
- **没选中的选项要存在感很低**，让眼睛不被分散
- 选中那一刻要**有轻微的「啊哈」反馈**

**关键帧：选中反馈瞬间**

```
用户点击「旧纸页的微苦」

第 80ms: 卡片缩 0.97
第 200ms: 卡片缩放回弹到 1.02（轻微 overshoot）
第 250ms: 边框加粗、底色变深、字重变粗
第 350ms: 切换到下一题（卡片从右滑入 300ms）

「啊哈」反馈：让用户感觉「这一题选得对」
```

### 设计师该干嘛

**出 3 个状态稿**：

| 状态 | 出什么 |
|------|--------|
| 首题（第 1/10） | 进度条 0%，新鲜感 |
| 中题（第 5/10） | 进度条 50%，激励气泡「已完成一半 ✓」 |
| 末题（第 10/10） | 进度条 100%，「即将揭晓…」 |

**校准题单独出 1 稿**（多选网格，与主问卷视觉有区分）。

## 场景 4：揭晓人格，被命名的那 5 秒

### 情境

```
时间：00:08
动作：点完最后一题 → 翻书转场动画 1000ms → 揭晓区出现
心理：「我的灵魂人格是什么？」
```

### 用户情绪

```
期待（峰值）→ 被命名（峰值）→ 想被读懂（持续）
```

### 画面关键帧

**揭晓区**

```
┌────────────────────────────────────┐
│  ▓▓▓▓▓▓▓▓▓▓▓ 深琥珀渐变背景 ▓▓▓▓▓ │
│  ▓▓▓▓▓▓（下方亮、上方暗）▓▓▓▓▓▓ │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
│                                    │
│         ═══ CRUSH FRAGRANCE ═══   │
│           ── 走过 10 道情境题 ──    │
│                                    │
│                                    │
│           你的灵魂人格              │
│                                    │
│                                    │
│              暗流                  │  ← 人格名 64px 衬线
│                                    │    blur(20px)→0  700ms
│                                    │
│            The Undertow            │  ← 英文小字 14px
│                                    │
│                                    │
│     「不喧哗，但无法被忽视」       │  ← tagline 手写感 18px
│                                    │
│                  ✨                 │  ← 中央光晕呼吸
│                                    │
│                                    │
│          [继续阅读 ↓]              │  ← CTA 渐显
│                                    │
└────────────────────────────────────┘
```

**视觉意图**：
- **整个产品最重要的 5 秒**，设计师 30% 精力放这
- 揭晓瞬间是「被命名」，不是「被告知」
- **背景一定要深**，让「暗流」两个字发光
- 中央光晕呼吸（loop），引导视线焦点
- **不要用人脸**，用香材特写或抽象图形

**关键帧：揭晓瞬间动画分解**

```
帧 1（0ms）  : 前一页翻书感消失
帧 2（200ms）: 深琥珀渐变背景从下覆盖
帧 3（400ms）: 「你的灵魂人格」胶囊滑入
帧 4（800ms）: 「暗流」两字开始从模糊变清晰
              （blur 20px → 0，时长 700ms ease-out）
帧 5（1500ms）: tagline 手写感文字逐字淡入
帧 6（1700ms）: 光晕开始呼吸（4s 循环）
帧 7（2200ms）: 「继续阅读 ↓」渐显
```

### 设计师该干嘛

**出 3 个角度**：

| # | 角度 | 用途 |
|---|------|------|
| A | **氛围图主导**（用香材/烛光特写做底图） | 适合品牌冷启动 |
| B | **抽象几何主导**（线条 + 渐变 + 极小符号） | 适合日常更新 |
| C | **纯文字主导**（无大图，只有字+光晕） | 极简、文艺感最强 |

**设计师选 1 个深化 + 出 5 段动画分解稿**。

## 场景 6：付费墙，值不值的 3 秒判断

### 情境

```
时间：00:12
动作：滚到「本命香推荐」→ 第 1 张「阿蒂仙 冥府之路」免费看
      第 2 张「汤姆·福特 暗夜幽兰」blur 模糊
      点击「解锁完整版」→ 付费墙抽屉滑入
心理：「9.9 元？我要不要掏这个钱？」
```

### 用户情绪

```
值不值判断（峰值 3 秒）→ 犹豫 → 妥协或离开
```

**视觉意图**：
- **3 档中最强是「¥9.9 完整版」**（实心琥珀、最受欢迎徽章、5 折）
- **¥6.6 裂变档**给不愿付 ¥9.9 的人出口（描边弱化）
- **¥19.9 订阅盒**给高端用户（粉色装饰、实物感）
- **原价划线 + 5 折徽章** 是锚定心理
- 「最受欢迎」徽章**一定要旋转斜贴**

**关键帧：抽屉滑入分解**

```
帧 1（0ms）   : 背景遮罩 fade in（200ms）
帧 2（200ms） : 卡片从底部 slide up（350ms ease-out）
帧 3（550ms） : 内容 stagger fade-in
帧 4（800ms） : 3 档卡片 hover-ready
帧 5（1200ms）: 进度环开始脉冲呼吸
```

## 设计师速读：5 个情绪基调

| 基调 | 视觉对应 |
|------|---------|
| **温暖** | 主色：暖琥珀；背景：奶油色；留白多 |
| **克制** | 不用全屏图，用留白呼吸；信息密度低 |
| **感性** | 字体：衬线 + 手写感；图标：手绘风 |
| **精致** | 间距：4 的倍数；圆角：大圆角 16–24；阴影：柔 |
| **呼吸** | 段落 1.75 行高；段落间 24–40；颜色不对比强烈 |
