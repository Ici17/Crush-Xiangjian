# 「令人心动的记忆点」产品文档

> 版本：v4 · 上线日期：2026-08-12 · 负责人：Alex（产品） · V2 文案升级（C反转+D共识定调）

---

## 1. 区块定位

**位置**：结果页 → 香气图谱（三调图）之后、三支香水推荐之前。

**场景**：用户完成12题测试后，查看自己的「香气人格报告」。本区块在专业三调图与三支香水之间，用一段叙事文案承接用户的好奇和情绪。功能上属于**情绪锚点**——让用户在理性阅读（图谱）和下一步行动（选香）之间，停留、被打动、产生收藏/分享冲动。

**锁定态**：同等显示，不设遮罩。免费态也能看到，属于获客层内容。

---

## 2. 一句话定义

> 一段**动态生成的高级叙事**——不套模板、不写死16条——根据你测出来的人格和匹配到的那支香，告诉你「你的味道是什么感觉」，像读到一篇关于自己的微型文学评香。

---

## 3. 文案风格定调

| 维度 | 标准 |
|------|------|
| **人格设定** | 第二人称「你」，香评师视角，私密、有距离感 |
| **情绪基调** | 高级克制型，不讨好、不煽情、不套小红书模板 |
| **叙事手法** | 每个变体是一段独立叙事，不拼接 opener/scene/anchor/closer |
| **灵感来源** | 观夏（To Summer）文案 —— 安静、有画面、像悄悄告诉你一个秘密；Le Labo 命名诗 —— 留白、有深度、不让所有人都懂 |
| **品牌声线** | 不同香水品牌有不同叙事性格：Byredo 北欧阳克制、Tom Ford 沉稳权力、YSL 反叛自由、Diptyque 左岸审美、Chanel 经典体面、Aesop 智性极简、MFK 肌肤暖意、Amouage 华丽极致、Le Labo 都市冷智、Hermès 低调奢侈、Creed 安静贵族 |

## 4. 动态生成逻辑（运营可理解版）

### 不是怎么做，是什么决定什么：

```
用户的测试结果 → 人格名（如「暗流」）
                 ↓
人格的本命香    → 品牌（如 Byredo）+ 香水三调（如 粉红胡椒/玫瑰/沉香/广藿香/麝香）
                 ↓
品牌声线池     → Byredo 有 5 支叙事变体，算法根据「人格描述 + 香调特征」的哈希值选一支
                 ↓
最终输出       → 一段完整叙事文案，同一人格每次刷新不变（稳定锚定）
```

### 三个关键规则：

1. **不提香水名和品牌名** —— 读者闻的是「自己的味道」，不是商品标签
2. **同一品牌不同人格不撞文案** —— 算法保证每家品牌的叙事池内，16 个人格走不同变体（当前线上 0 碰撞）
3. **文案不固定不死** —— 未来新增人格或调整香水匹配，文案自动更新。不是改 16 行文本的事

## 5. 16 格线上文案（2026-08-12 V2 生效）

| 人格 | 关联品牌 | 文案 |
|------|---------|------|
| **暗流** | Byredo | 有人说过你太安静吗？你大概笑了一下。不是不爱说话——是你分得清倾诉和表演。话是说给人听的，不是说给人看的。像冬夜里一扇亮着的窗，不招摇，也不关。偶尔有人路过，站在外面看了很久。你也没开口。不是不想——是想等那个人，自己推门。 |
| **荒岛** | Diptyque | 你在画廊待了很久。不是在看画——是在等一幅让你站不住脚的。随便选不难，难的是选了之后不后悔。你不是挑剔。你是见过光之后，不想再回暗处。那种不肯将就，是你对自己为数不多的温柔。 |
| **残温** | Creed | 他们觉得你不热情。你没解释。热情和热闹不是一回事——你的温度不挂在脸上，挂在事上。不声张的体面，比名片重。有人帮你之后说「跟你做事很舒服」。你没回。但那天你记得比谁都清楚。真正贵的东西，都安静——你也一样。 |
| **裂岸** | Tom Ford | 有人说你不好亲近。你没反驳。亲近从来不是你的目标——你在乎的不是距离，是分寸。退后半步看全局，比冲在前面的十个都清醒。你不是不给机会——是机会得配得上你的认真。不是谁都接得住这种沉。你也没等。 |
| **寒岭** | Le Labo | 他们说你「看起来没什么」。你习惯了。不是没东西——是你不摆出来。第一层是好闻，第二层是稳，翻到第三层才知道你藏着的东西有多深。可多数人走到第一层就停了。你没拉他们。不是骄傲。是觉得——有些东西，只有自己翻到的人，才配得上。 |
| **极夜** | Amouage | 有人觉得你「太过了」。你没收。不是不懂收敛——是满到装不下将就。你不是来配合这个世界的。你是来让那些跟你一样「太过了」的人，看到一种可能性。与其收着活，不如满着过。你选了后者。 |
| **砾迹** | Hermès | 他们第一眼看你可能没注意到。你不是那种一进屋就抢光的人。但你像一块被人坐了很多年的木桌——每次有人起身，都会回头看一眼。不是不耀眼。是不需要用耀眼来证明什么。那种旧，不是旧。是时间替你选过一遍之后，剩下的。 |
| **冲浪** | YSL | 旁人说你活得太随便。你懒得反驳——解释比玩更累。你只是不按别人的剧本走，不是没剧本。你定的规矩比谁都严：可以疯，不能假；可以换路，不能骗自己。他们以为自由是什么都不在乎。你不知道怎么解释——真正的自由是你想在乎什么，就在乎什么。 |
| **温砾** | MFK | 有人说你太好说话了。你没否认。好说话不是没底线——是你的底线不需要亮出来。温柔不是弱点。是你选的。像晒过太阳的棉麻，软，却有骨子里的干净。那种舒服不是退让——是你分得清，哪些值得争，哪些不值得。 |
| **空号** | Aesop | 他们觉得你「东西太少」。你懒得解释——少不是没有，是每样都选过。别人在加，你在减。减到只剩对的东西。极简不是不在乎。是在乎到了极致——所以一件不对的，都装不下。 |
| **冷砚** | Diptyque | 有人说你太冷。你跟自己笑了一下。你不是冷——是你懒得对每个人都热。像左岸那间不肯关门的画廊，冷着脸，可走进去才发现——墙上挂的全是烫的东西。将就这两个字，你从来不认识。但你知道，能走进去的人，也不用你解释。 |
| **渊海** | Le Labo | 他们觉得你不好接近。你没改。不是不给人温度——是你的温度要坐下来才能感觉到。那种清醒底下，是一种很深的、不声张的温柔。不急着烫人。慢慢热起来的人，反而更难冷。只是不是谁都坐得下来。 |
| **沉湾** | Diptyque | 有人说你不懂浪漫。你大概没解释。你的浪漫不是张灯结彩的那种——是月光落在水面上。看得见，捞不起。安静，但一直亮着。那种浪漫不需要回应。它就在那里，像你知道一件美好的事，不需要任何人确认。 |
| **霜冷** | Chanel | 他们说你不太好接近。你没否认，也没生气。你不是冷——你是太清楚自己能给多少温度。像一条不常戴的珍珠项链，不亮给别人看，但打开盒子的时候，光还是满的。你不是那种一进门就震住全场的人。你是那种他们意识到刚才那个空——是你留下的。 |
| **荒原** | Diptyque | 有人说你太敏感了。你没否认。不是你比别人多心——是你比别人多一层。风一吹你先听见，话没说你先懂。那种敏感不是脆弱——是天然地比世界多一根天线。累吗？累。但你换不掉。它让你比别人早一点看到光。 |
| **烬生** | MFK | 他们以为你不花心思。你大概在心里笑了。不是不花——是你花在别人看不到的地方。穿什么，什么就像长在你身上。不刻意。不解释。最好的味道不是让人记住你喷了什么。是让人只记得——你。那种自然，是花了很久才看起来不费力的。 |

## 7. 用户行为路径

```
结果页滚动 → 看到三调雷达图（理性认知）
             ↓
          「令人心动的记忆点」（情绪停留）
             ↓
          三支香水推荐卡片（行动决策）
```

**关键转化点**：这个区块是「认知 → 行动」的情绪桥梁。用户在这里被戳中、被打动，才会带着情绪去看香水、点分享、做付费解锁。

## 8. 与竞品的差异

| 维度 | 大众测试（MBTI 类） | Crush 香鉴 |
|------|-------------------|-----------|
| 结果页文案 | 固定 16 条模板化描述 | 动态生成，品牌×人格双重声线 |
| 文案风格 | 星座式笼统夸奖 | 沙龙香评式克制叙事 |
| 可扩展性 | 改 16 行文本 | 改香水匹配或品牌叙事池即可，自动生效 |
| 品牌感 | 无品牌关联 | 每支文案隐形对齐真实沙龙香品牌声线 |

## 9. 后续可迭代方向

1. **分享图接入「记忆点」段落** —— 目前分享图只展示人格名+香水名，未来可把本文案嵌入 self 场景分享图
2. **新增品牌叙事池** —— 当香水库扩展到 200+ 支覆盖更多品牌时，补充对应声线变体池
3. **测试入口预览句** —— 首页 16 个胶囊上浮一段「你的气味，大概是……」作为记忆点的一句话预告
4. **A/B 测试** —— 不同叙事密度（一段 vs 两段）、有无分隔线、有无标题，测停留时长
