## 0. 阅读须知（先看）

### 这份文档是什么

是给**设计师**的，不是给开发的。开发实现已经完成（代码仓库可用），设计师的任务是：

- ✅ 把「**能用的开发稿**」升级到「**品牌级视觉**」
- ✅ 把「**功能逻辑**」包装成「**情绪体验**」
- ✅ 把「**通用组件**」打磨成「**有质感的产品语言**」
- ❌ 不需要重写交互逻辑（业务规则已锁）
- ❌ 不需要重新数据建模（16人格/110香水/10题都已定）

### 阅读顺序

1. 第 1–3 节：理解产品情绪（30 min 速读）
2. 第 4–7 节：死记硬背设计令牌和动效规则（1 h）
3. 第 8 节：知道页面关系（15 min）
4. 第 9–14 节：逐页出稿（核心工作，3–5 天）
5. 第 15–17 节：组件库整理（出稿同步进行）
6. 第 18 节：分享图模板（必交付）
7. 第 19–25 节：交付前自检

### 三条铁律（违反任何一条稿子重做）

1. **H5 移动优先**：所有稿子以 **iPhone 14 Pro Max（430×932）** 为基准（可视信息密度更高，适配当代旗舰机型）

3. **不要俗气**：廉价金、少女粉、ins 风字 = 这单黄了

## 1. 产品一句话 + 核心场景

### 一句话定义

> **Crush香鉴** —— 用 10 道情境题，找到「你的灵魂藏在哪种香气里」的香水人格测试 H5。

### 三句话

- 不是香水测评，是「**灵魂香气人格**」的小测试
- 不是数据报告，是「**被温柔看见**」的体验
- 不是工具应用，是「**深夜独处仪式感**」的娱乐消费品

### 核心场景

```
22:00  单身女生，窝在沙发，深夜刷朋友圈
      ↓
 00:30 刷到 Crush 香鉴分享图（朋友做的）
      ↓ 「她的本命香是「暗流」？我也想做」
      ↓ 点进 H5
      ↓
 00:35 沉浸式做完 10 题（约 2 分 30 秒）
      ↓
 00:38 揭晓人格 → 性格解读 → 雷达图 → 本命香 3 支
      ↓ 「这说的不就是我吗」
      ↓
 00:40 付费解锁完整报告 → 生成分享图 → 发朋友圈
      ↓
 02:00 朋友圈 9 个赞，3 个朋友点链接
      ↓
次日 14:00 朋友做完测试 → 朋友圈分享「我和她的香气匹配度」→ 二次裂变
```

### 北极星指标

| 阶段 | 指标 | 当前 | 目标 |
|------|------|------|------|
| 落地 → 开始测试 | CTR | ~30% | **45%** |
| 题目完成率 | 完成/开始 | 待测 | **80%** |
| 揭晓→分享 | 分享/揭晓 | 待测 | **20%** |
| 揭晓→付费 | 转化率 | 待测 | **5%** |
| 分享→新用户 | K 因子 | 待测 | **0.6** |

> **设计师请记住**：你的每一个像素都在直接影响这 5 个指标。

## 2. 用户画像与情绪锚点

### 主要用户（70%）

- **女，22–32 岁，一二线城市**
- **职业**：白领、设计/媒体/互联网、自由职业
- **月可支配**：5000+ 元
- **香水习惯**：1–3 瓶在用，看重「风格匹配」不追大牌
- **内容偏好**：小红书重度、Notion 用户、网易云年度乐单
- **审美关键词**：克制、细节、有呼吸感、不喧哗

### 次要用户（30%）

- 男士（25–40，高知，送礼场景）
- 学生党（18–22，自我探索）

### 用户情绪锚点

```
进入测试前   ：好奇 + 一点点仪式感期待
做题中       ：沉浸（故事代入感，不能打断）
揭晓瞬间     ：被看见、被命名（最关键的 5 秒）
解读阅读     ：认同、被理解（文字要有刺痛感）
看到本命香   ：拥有欲 + 实用诉求
看到付费墙   ：值不值（视觉要压得住野心）
看完报告     ：想被认可 → 主动分享
被朋友匹配   ：社交货币（要能截图发圈）
```

### 用户不喜欢的

- ❌ 测试结果页面像 MBTI 测评网站（用户已审美疲劳）
- ❌ 香调直接列「前中后调」（专业感过强，劝退小白）
- ❌ 心理学词汇堆叠（人格、原型、潜意识的乱炖）
- ❌ 把付费墙放在揭晓区上面（侮辱感）

## 3. 设计愿景（设计师发力方向）

### 3.1 一个比喻

> 想象你走进一条不张扬的小巷，拐角处有一家没挂招牌的香水店。
> 老板娘递给你试香纸时轻声说：「涂在手腕，等它醒来」。

**这是 Crush香鉴 应该有的气质**。

### 3.2 五个关键词（每个对应一类设计选择）

| 关键词 | 设计决策 |
|--------|---------|
| **温暖** | 主色：暖琥珀；背景：奶油色；留白多 |
| **克制** | 不用全屏图，用留白呼吸；信息密度低 |
| **感性** | 字体：衬线 + 手写感；图标：手绘风 |
| **精致** | 间距：4×n；圆角：大圆角 16–24；阴影：柔 |
| **呼吸** | 段落 1.7 行高；段落间 24–40；颜色不对比强烈 |

### 3.3 参考坐标（不抄袭，方向对）

- **Aesop 官网** — 排版呼吸感、克制的金棕
- **Le Labo** — 诚实感、材质感、留白多
- **Diptyque 蜡烛** — 暖光、私密、慢
- **Call Me By Your Name 电影海报** — 怀旧光感
- **Niko June / Aesop 包装** — 不喧哗的精致

### 3.4 三个不要（反面清单）

- ❌ **不要 ins 仙气**：粉色 + 烫金 + 大字
- ❌ **不要国潮**：红 + 黑 + 楷体
- ❌ **不要开架香水**：金属 + 闪烁 + 重投影

### 3.5 体验宣言（贴在墙上）

> 我们不卖香水的功能数据，我们卖「被温柔命名」的那 5 秒。
> 我们不解释什么是香调，我们让用户闻到画面。

### 4.1 品牌名与标识

| 项目 | 内容 |
|------|------|
| 中文名 | Crush 香鉴 |
| 英文名 | **CRUSH FRAGRANCE** （品牌符号固定词） |

| 品牌音效 | 选中揭晓/付费成功时一声「叮」（温暖木琴音，非系统提示音），可选 |

### 4.2 Logo 使用规范

- **最小尺寸**：移动端 64×64 px
- **安全距离**：四周 ≥ Logo 高度的 1/4
- **品牌色背景**：可单色应用，禁止渐变 / 图像填充
- **不可变形**：不允许拉伸、旋转、改色（除单色应用）

### 4.3 品牌符号 `CRUSH FRAGRANCE`（文字标）

- 字距：`letter-spacing: 0.3em`（大幅字距营造「高级感」）
- 字体：Noto Serif SC 700（小写字母上方加衬线感）
- 颜色：深琥珀 `#2C1810` 或 浅奶油 `#FAF3EA`（视背景而定）
- 长度：水平横线（1px 琥珀色）作上下边框，宽度跟随文字宽度 +32px
- **应用位置**：落地页顶部品牌区、所有页面 Footer、分享图顶部

## 7. 动效系统（必须按此实现）

### 7.1 三类动效准则

| 类型 | 触发 | 时长 | 缓动 | 强度 |
|------|------|------|------|------|
| **微交互** | hover/tap/选 | 80–250ms | ease-out | 轻微（≤4px） |
| **转场** | 路由切换 | 300–500ms | ease-in-out / spring | 中度（≤24px） |
| **仪式动画** | 人格揭晓 | 700–1200ms | spring with overshoot | 强（可 blur+缩放） |

```css

--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
--ease-soft: cubic-bezier(0.4, 0, 0.2, 1);  /* Material 标准 */
```

### 7.5 仪式动画（核心体验，必须出彩）

#### A. 人格揭晓（最重要时刻）

```
时间线（总 1500ms）：
  0ms     前一个画面 final fade 200ms
  200ms   黑色遮罩从下覆盖新位置 400ms ease-out
  400ms   「你的灵魂人格」胶囊从下方滑入 400ms -spring
  800ms   人格名（最大字）blur(20px)→blur(0) 700ms -ease-out
  1000ms  人格英文/代号 fade-in 300ms
  1500ms  tagline 手写感文字（Ma Shan Zheng）逐字淡入 600ms
  1700ms  光晕 pulse loop (infinite, 4s)
  2200ms  「继续阅读」CTA 渐显
```

#### B. 雷达图绘制

```

完成后数据点保持 0.7 透明度悬浮呼吸
```

#### C. 香水卡入场

```
3 张卡横向 stagger 入场，每张 400ms
```

#### D. 付费墙滑入

```

  0-200ms   遮罩 fade
  200-550ms 卡片 slide up from bottom (350ms -ease-out)
  550ms+    内容 stagger fade-in
```

## 21. 性能预算与加载策略

|------|------|------|

| 总包大小 | < 500KB | 全部静态资源 |

| 资源 | 策略 |

| Stripe | 仅点击支付按钮时加载 |

### 21.3 图片规范

- **格式**：WebP / AVIF（fallback JPG/PNG）
- **尺寸**：基于 `<picture>` 响应式
  - 朋友圈分享卡 1080×1080 WebP，~80KB
  - 桌面氛围图 1600×1200 WebP，~120KB
- **懒加载**：`loading="lazy"` + `decoding="async"`
- **预加载**：首屏氛围图可 `<link rel="preload">`

### 21.4 SSR vs 静态导出

当前架构：Next.js 16 + `output: 'export'`
- 优势：CDN 友好、首屏快、易部署
- 代价：localStorage 不能 SSR，需要客户端 hydration
- **设计稿适配**：所有内容必须在 html 加载完之前在骨架屏展示
