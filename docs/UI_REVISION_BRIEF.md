# Crush香鉴 UI 整改方案

> 致设计师：这不是单页设计，是 4 个独立页面的 H5 产品。请按以下结构重新出图。

---

## 核心问题

你目前只做了**落地页（首页）**，而且：
- ❌ 把多页内容强行塞进一页
- ❌ 缺少氛围图、人格预览、品牌符号
- ❌ 按钮文案错误（「测试」→ 应该是「寻找/发现」）
- ❌ 完全没做问卷页、结果页、朋友匹配页

**这不是视觉优化，是结构性重做。**

---

## 产品架构（4 个独立页面）

```
┌─────────────────────────────────────────────────────────┐
│  落地页 /          →  问卷页 /question    →  结果页 /result  │
│  (吸引点击)            (10 道情境题)         (人格+香水+付费墙) │
│       ↓                                                    │
│  朋友匹配页 /friend (可选，双人格对比+分享图)                  │
└─────────────────────────────────────────────────────────┘
```

## 页面 1：落地页 /

**目标**：3 秒内让用户点击「开始寻找我的本命香」

### 当前问题 vs 整改要求

| 元素 | 现状 | 整改要求 |
|------|------|----------|
| **氛围图** | ❌ 完全没有 | ✅ **必须加**：琥珀暖光下的香水瓶/香材局部，参考 Aesop/Le Labo 产品摄影 |
| **品牌符号** | ❌ 只有文字 Logo | ✅ 设计抽象「香气波纹」或「灵魂光晕」图形符号 |
| **16 人格预览** | ❌ 只有数字 | ✅ 16 个胶囊标签横向滚动展示，营造专属感 |
| **CTA 文案** | ❌ 「开始测试」 | ✅ 「**开始寻找我的本命香**」或「**发现我的灵魂香气**」 |
| **数据条** | ❌ 三栏平铺 | ✅ 视觉权重递减：16(最大) → 225(中) → 10(小)，暗示「从多到精」 |
| **示例报告入口** | ❌ 放在 CTA 下方抢视线 | ✅ 改为右上角小字幽灵按钮，或首屏底部淡入 |

### 首屏结构（从上到下）

```
┌─────────────────────────────┐
│  [品牌符号]  CRUSH FRAGRANCE │  ← 顶部，小字
├─────────────────────────────┤
│                             │
│    [氛围图：琥珀暖光香瓶]     │  ← 必须，占首屏 30-40%
│                             │
├─────────────────────────────┤
│        Crush                │  ← 主标题，衬线体
│         香鉴                │
├─────────────────────────────┤
│   你的灵魂，藏在哪种香气里？  │  ← 副标题
├─────────────────────────────┤
│  16 → 225 → 10              │  ← 数据条，递减字号
│ 人格  香水  情境题            │
├─────────────────────────────┤
│  [暗流] [荒岛] [残温]...     │  ← 16 人格胶囊，横向滚动
│  (16 个标签，可左右滑动)       │
├─────────────────────────────┤
│                             │
│   ┌───────────────────┐     │
│   │ 开始寻找我的本命香 → │   │  ← 主 CTA，琥珀色实底
│   └───────────────────┘     │
│                             │
│   查看示例报告               │  ← 幽灵按钮，小字
│                             │
└─────────────────────────────┘
```

### 设计参考

- **摄影风格**：Aesop 官网产品页、Le Labo 香水瓶特写、暖光、浅景深
- **配色**：深琥珀 `#2C1810` / 暖琥珀 `#D4A574` / 奶油 `#FAF3EA`
- **字体**：Noto Serif SC（标题）+ Noto Sans SC（正文）

## 页面 2：问卷页 /question

**目标**：让用户沉浸完成 10 道题，不跳出

### 页面结构

```
┌─────────────────────────────┐
│ ← 返回        3/10    [跳过] │  ← 顶部栏：返回、题号、跳过
│ ████████░░░░░░░░░░          │  ← 进度条，琥珀色渐变
├─────────────────────────────┤
│                             │
│   [情境标签：深夜独处]        │  ← 小胶囊，当前情境
│                             │
│   凌晨两点，你独自在家，      │  ← 题目，大字，衬线体
│   会选择什么陪伴自己？        │
│                             │
├─────────────────────────────┤
│                             │
│   ┌─────────────────────┐   │
│   │ A                   │   │  ← 选项卡片，白底
│   │ 点上蜡烛，翻开一本   │   │     悬停/选中：琥珀边框+
│   │ 旧书，让纸香弥漫    │   │     阴影+微上移
│   └─────────────────────┘   │
│                             │
│   ┌─────────────────────┐   │
│   │ B                   │   │
│   │ 打开窗户，让夜风和   │   │
│   │ 远处的雨声进来      │   │
│   └─────────────────────┘   │
│                             │
├─────────────────────────────┤
│                             │
│   ┌─────────────────────┐   │
│   │    继续探索 →       │   │  ← 底部固定按钮
│   └─────────────────────┘   │
│                             │
└─────────────────────────────┘
```

### 关键要求

- **选项文案**：必须是**微型故事**（20-30 字），不是短标签
  - ❌ 玫瑰香 / 木质香
  - ✅ 二手书店角落翻到旧票根，空气里微苦的纸香
- **选中态**：边框变琥珀色 + 阴影 + 显示「前往[某路径]」
- **进度条**：顶部固定，随滚动始终可见

## 设计规范（锁定，不要改）

### 色彩
- 深琥珀 `#2C1810` — 标题、强调
- 暖琥珀 `#D4A574` — 按钮、高亮
- 背景奶油 `#FAF3EA` — 全局背景
- 卡片白 `#FFFFFF` — 卡片背景

### 字体
- 标题：Noto Serif SC，700/600
- 正文：Noto Sans SC，400/500

### 圆角
- 卡片：24px
- 按钮：全圆角（pill）
- 标签：全圆角

### 阴影
- 卡片：`0 2px 8px rgba(44,24,16,0.08)`
- 悬浮：`0 4px 16px rgba(44,24,16,0.12)`
