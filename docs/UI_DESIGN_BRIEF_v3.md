## 2. 朋友匹配轻量版 — 全新页面设计（优先级 🔴）

这是本次最重要的新功能，也是**设计师最需要投入**的页面。

### 2.1 业务逻辑（已锁定）

```
我测完 → 结果页点「生成邀请链接」→ 链接：https://domain/friend?inv=<我的personalityId>
→ 微信转发给朋友 → 朋友点开 → 朋友测完 → 自动出我和朋友的香气匹配结果
→ 朋友可下载分享卡 / 复制分享文案 → 继续裂变
```

**关键角色变化**：
- 朋友页现在是**朋友视角**——朋友是被邀请者，看到的是「你和朋友的匹配」而非「我选两个人格」
- 如果朋友**没有测试过** → 引导去做测试 → 测完自动回跳匹配页

### 2.3 分享卡设计要求

**核心用途**：朋友测完匹配后，发朋友圈 / 小红书展示

| 格式 | 尺寸 | 用途 |
|------|------|------|
| 朋友圈版 | 1:1 正方形 | 微信朋友圈 |
| 小红书版 | 3:4 竖版 | 小红书 |

**分享卡内容**（设计师布局）：
1. 顶部：Crush香鉴 logo（极小，不抢主体）
2. 主体：双人格名 + 匹配分 + 评级徽章
3. 共鸣香调标签（2–3 个）
4. 一句场景故事（1–2 句）
5. 底部：Crush香鉴小程序码 或 短链（带水印版 vs 去水印版）

**两个版本**：
- 带水印版（免费用户）→ 底部加强水印
- 去水印版（付费 ¥9.9 用户）→ 干净无水印

### 2.4 双雷达对比设计

要求：两条雷达在同一坐标系，颜色区分「我 / 朋友」，中心对齐，轴标签清晰。

推荐配色：
- 「我」：`#D4A574`（暖琥珀，填充 40% 透明度）
- 「朋友」：`#7DB9B6`（清海蓝，填充 30% 透明度）
- 中心虚线对齐，轴线 `#E8C5A0`
