## 1. 产品概述（当前状态）

### 1.1 是什么

**Crush香鉴** ——「灵魂香气人格测试」H5。用户做 10 道情境题 → 得到 16 种香气人格之一 → 获得本命香水推荐（3 支）+ 可和朋友做香气匹配 + 生成分享图。

核心场景：**深夜刷手机 → 被文案吸引 → 3 分钟测完 → 分享到朋友圈/小红书 → 裂变**。

### 1.2 当前产品结构（5 个页面 + 2 浮层）

| 页面 | 路由 | 已实现核心功能 |
|------|------|------|
| 落地页 | `/` | 品牌叙事 + 数据展示（16人格·225香水·10题）+ 测试入口 |
| 问卷页 | `/question` | 7 层分支题 + 3 道校准题，二选一，进度保存 localStorage |
| 结果页 | `/result` | 人格揭晓 + 性格解读 + 雷达图 + 深度报告 + 本命香水×3 + 人格专属探索 + 付费墙 + 分销进度 |
| 朋友页 | `/friend` | 双人格香气匹配 + 兼容分圆环 + 双雷达对比 + 场景故事 + 分享图下载 |
| 支付面板 | （浮层） | Stripe 收银台（微信/支付宝/信用卡）+ 3 档定价 |

### 1.3 目标用户

- **主力**：20–35 岁女性，一二线城市
- **情感需求**：自我探索、精致生活仪式感、社交货币
- **行为**：高审美、易被细节打动、愿为情绪价值付费
- **设备**：95% 手机微信 / Safari，iOS + Android 均需适配

## 2. 设计愿景（已锁定，不要推翻）

### 2.1 核心形容词

**温暖、克制、感性、精致、有呼吸感**

不是 ins 仙气风、不是北欧极简冷淡、不是国潮大字报。是介于之间的：**被温柔对待的成年人的私密仪式感**。

### 2.2 视觉隐喻

> 深夜，蜡烛点燃，一杯威士忌在手边。你闻了闻手腕，笑了。

- 暖琥珀色光感（不是金灿灿）
- 羊皮纸 / 旧书页质感纹理（低调）
- 手写体 + 衬线体并置
- 留白即是呼吸

### 2.3 参考方向

```
方向感（设计师在此框架内自由发挥）：
1. Aesop 官网 — 克制的温暖、排版呼吸感
2. Le Labo 香水店 — 材质感、诚实感
3. Gentle Monster — 有个性的精致
4. 电影《Call Me By Your Name》— 暖光、怀旧、情感浓度

避免：少女粉系 / 国潮大字报 / 开架香水俗气感
```

### 3.6 动效规范（设计师需补齐）

- **原则**：入场轻、响应即时（<100ms）、同屏不超 1 个主导动画
- **缓动**：`ease-out cubic-bezier(0.16,1,0.3,1)` · `ease-in-out cubic-bezier(0.65,0,0.35,1)` · `spring cubic-bezier(0.34,1.56,0.64,1)`
- **转场**：首页→问卷 350ms 淡出+上移；问卷→结果 400ms 翻书感；结果→朋友 500ms 共享元素
- **微交互**：按钮 `scale(0.97)` 80ms；卡片 `translateY(-2px)` 200ms；选项选中 250ms；雷达图 0→目标 700ms stagger 60ms；分数圆环 1000ms；香水卡入场 400ms stagger 100ms；付费墙底部滑入 350ms

### 3.7 图标

- 线性图标 2px 线宽圆角端点；20/24/32px；跟随文字色或琥珀色
- 推荐 Phosphor Icons 或自定义手绘感小图标
- 香调装饰可用 🌸🌿🌊✨🍋🍫 但不作主图标

## 4. 页面设计规范（当前真实结构）

### 4.1 落地页 `/`

**首屏必含**：品牌符号 + 主标题「你的灵魂，藏在哪种香气里」+ 副标题 + 氛围图 + 16 人格预览胶囊 + CTA「开始寻找我的本命香」（首屏可见，不滚动）。

**数据条**：`16 灵魂人格 · 225 本命香水 · 10 情境题`（三栏，琥珀色，字号递减）。

**设计要求**：氛围图建议琥珀暖光下的香水瓶局部/香材，不要真人正脸；人格预览用 16 个小胶囊营造专属感；文案用「寻找/发现」不用「测试/问卷」。CTA 下滑后可变固定底栏。

### 4.2 问卷页 `/question`

**结构**：顶部进度条（题号/总题数 + 动画）→ 情境题卡片（大字情感化）→ 两选项卡片（微型故事 20–30 字，不是短标签）→ 返回上一题（幽灵按钮）。

**交互**：选中高亮+放大，未选中淡出，下一题滑入；进度条流畅增长；支持手势返回。

**文案风格**：
```
❌ 玫瑰香 / 木质香
✅ 二手书店角落翻到旧票根，空气里微苦的纸香
✅ 海边民宿早晨推窗，海风混着柑橘和岩石的气息
```

### 4.3 结果页 `/result`（核心页，小节从上到下）

```
① 揭晓区       探索路径标签 →「你的灵魂人格」胶囊 → 人格名(超大) → MBTI别名 → tagline
② 性格解读     段落正文（情感浓度高）
③ 香调偏好图   Recharts 真实雷达（6 维）+ 一句香调方向
④ 灵魂解读报告 4 维度：核心信息 / 性格分析 / 用香哲学 / 成长建议
⑤ 人格专属探索 横向滑动 Mini 香水卡（基于人格的额外推荐，全免费可见）
⑥ 本命香水推荐 3 张卡：本命香(免费) / 进阶香 / 平替香(需付费)
⑦ 付费墙       底部抽屉，3 档定价 + 分销进度条
⑧ 底部固定栏   重新测试 / 解锁完整版
```

**揭晓区（最重要时刻）**：仪式感，类似命运揭晓。背景深琥珀→暖琥珀垂直渐变；人格名 `clamp(3rem,10vw,5rem)` Noto Serif SC，字距 0.05em；揭晓动画建议 blur(20px)→聚焦 700ms。

**香水卡信息层级**：Tier 标签（本命香/进阶香/平替香，颜色区分）→ 中英文香水名 → 品牌 → 前/中/后调 → 扩香力+留香可视化条 → 价格区间 → 50 字描述。

**锁定态**：香水名+品牌可见，香调信息 blur，底部「解锁全部香调 →」。

**付费墙（3 档架构，已实现逻辑，需视觉优化）**：

| 档位 | 价格 | 原价(锚定) | 标签 | 说明 |
|------|------|-----------|------|------|
| 裂变特惠 | ¥6.6 | ¥9.9 | 省¥3.3 | 转发 3 人解锁，含完整版全部内容 |
| 完整版⭐ | ¥9.9 | ¥19.9 | 5折/最受欢迎 | 全部 3 支香水 + 深度报告 + 去水印分享图 + 购买链接 |
| 香气订阅盒 | ¥19.9 | ¥39.9 | 新品 | 实物 2–3 支小样寄送，不透露品牌 |

付费墙顶部含**分销进度条**（邀请 n/3，满 3 解锁 ¥6.6）。免费用户已得：本命香 + 基础人格 + 朋友匹配 + 带水印分享图。

> ⚠️ 已知文案不一致：「灵魂解读报告」实现为 4 维度，但定价副标题写「5 维度」。设计师定稿时统一为 4 维或修正文案。

### 4.4 朋友页 `/friend`

**结构**：标题+返回 → 双人格标签并列 → 朋友名字输入（实时反馈）→ 匹配按钮 → 结果区（分享卡 + 双雷达对比 + 兼容评级圆环 + 场景故事 + 互补解读）→ 分享操作栏（复制文案/下载图）。

**分享卡（核心，发朋友圈/小红书）**：正方形或 3:4；奶油底+纹理；顶部 Logo；主体双人格名+匹配分；兼容评级徽章；共鸣气味标签；场景故事 1–2 句；底部水印+短链。

**双雷达对比**：同色系不同透明度，中心虚线对齐，图例区分「我/朋友」。

## 5. 优化重点清单（设计师核心任务，按优先级）

### 🔴 P0 — 整体气质与首屏

1. **落地页首屏冲击力**：当前是功能性排版，需品牌级视觉。补氛围图（琥珀暖光香材/瓶身局部）、品牌符号、首屏 CTA 视觉重量。
2. **人格揭晓仪式感**：当前是静态大字。补揭晓动画（blur→聚焦 / 渐显 / 光晕），让「命运揭晓」有情绪落点。
3. **全站气质统一**：确保所有页面共享同一套氛围（背景纹理、光感、字体节奏），消除「开发稿」感。

### 🟠 P1 — 关键转化模块

4. **付费墙视觉**：逻辑已就绪（3 档+锚定+分销），但视觉朴素。需设计感卡片、原价划线呈现、信任元素（Stripe/微信/支付宝图标）、「最受欢迎」标签视觉、锚定节省金额突出。
5. **香水卡真实感**：当前无真实香水视觉。补瓶身占位/品牌调性视觉、Tier 色区分、锁定态 blur 处理、价格区间呈现。
6. **分享图模板**：当前 html2canvas 截图粗糙。出独立设计模板——朋友圈版(1:1)、小红书版(3:4)，含带水印版与去水印版（付费用户）。

### 🟡 P2 — 体验细节

7. **雷达图品牌化**：Recharts 默认样式去品牌化。重绘配色（6 调性辅助色）、轴线、网格、标签，统一到主色系。
8. **朋友页双雷达对比**：视觉区分「我/朋友」，对比强弱直观。
9. **微动效补齐**：按钮/卡片/选项/进度条的 hover/press/入场态按 3.6 规范补齐。
10. **人格专属探索横滑卡**：Mini 卡质感（瓶身缩略、Tier 点、香调标签）。

## 6. H5 特殊适配

- 安全区：`env(safe-area-inset-top/bottom)`（刘海 / Home Indicator）
- 视口：`<meta viewport="width=device-width, initial-scale=1, maximum-scale=1, viewport-fit=cover">`
- 微信：禁双击缩放、theme-color、OG 标签（title/description/image）、微信内支付唤起
- 性能：LCP<2.5s · FID<100ms · CLS<0.1 · 首屏 JS<150KB gzip · 图片 WebP 懒加载

---

## 7. 可访问性（a11y）

- 对比度：正文 ≥4.5:1，标题 ≥3:1
- 焦点可见：所有交互元素 `:focus-visible`
- ARIA：雷达图 `role="img"+aria-label`，模态 `role="dialog"`
- 字号：支持系统字号放大
- 动画：`prefers-reduced-motion` 减弱/关闭
- 表单：所有输入有 `<label>` 或 `aria-label`
